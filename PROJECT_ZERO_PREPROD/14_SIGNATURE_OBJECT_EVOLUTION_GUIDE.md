# PROJECT ZERO — SIGNATURE OBJECT EVOLUTION GUIDE (DOCUMENT 14)

> **Status:** Pre-Production (Planning Only) — **No code.**

---

## 0. Document Intent
Define the evolution of the **Signature Object** across the entire experience.

This object is the recurring identity anchor.

Because the exact archetype is not yet selected, we define evolution in **properties** (shape/material/animation/lighting/scale/meaning) so implementation can map to a chosen archetype later.

---

## 1. Signature Object Identity (Property-based)
### 1.1 Unchanging traits (must remain constant)
- Recognizable silhouette identity across all SOC states.
- Able to act as an **absorbing lens** during transitions.
- Able to host project-specific channels (energy/threads/rails) without changing base silhouette.

### 1.2 Changing traits (evolve per project)
- Material response
- Internal channel complexity
- Emission intensity profile
- Surface seam pattern

---

## 2. Evolution States (SOC-0 → SOC-8)

> Map these states directly to the “Signature Object State” fields in the storyboard.

### SOC-0 — QUIET SEED (Scene 0)
- **Shape:** embryonic core, minimal curvature
- **Material:** near-black stone core with faint internal emission
- **Animation:** ultra-slow breathing (micro pulse only)
- **Lighting:** minimal; only enough to guide typography emergence
- **Scale:** small relative to frame; feels like possibility
- **Meaning:** beginnings / decision
- **Transformation after project:** grows into “awake core” during Scene 1 exit
- **Transition interaction:** typography fragments drift into core

### SOC-1 — AWAKEN (Scene 1)
- **Shape:** seed becomes a lens-like monolith (slightly faceted)
- **Material:** dark alloy with faint glassy inner volume
- **Animation:** gentle rotation of internal light (very slow)
- **Lighting:** cool blue-violet key response
- **Scale:** slightly larger; more visible silhouette
- **Meaning:** journey begins
- **Transition interaction:** corridor particles funnel toward it

### SOC-2 — CONTRACT LATTICE ABSORPTION (LawLens-X)
- **Shape:** internal seams form clause-like segments
- **Material:** semi-transparent energy shell
- **Animation:** contract fragments orbit and then settle into lattice
- **Lighting:** cyan/violet scanning alignment; red outlier briefly colors internal channel
- **Scale:** moderate; acts as rebuild anchor
- **Meaning:** engineering learns to read contracts
- **Transition interaction:** contract pages dissolve into SOC-2 and reappear as pathways in next world

### SOC-3 — TRIAGE THRESHOLD CORE (Triage Assistant)
- **Shape:** three threshold chambers appear inside signature
- **Material:** energy core with soft volumetric glow
- **Animation:** thresholds pulse in order (stable final pulse pattern)
- **Lighting:** emerald/amber with precise red emphasis (rare)
- **Scale:** medium-large during title climax
- **Meaning:** emergency logic becomes clarity
- **Transition interaction:** green/yellow/red states compress into internal core and darken into mystery seed for next world

### SOC-4 — DETERMINISTIC RAILS NUCLEUS (Workplace Ops Agent)
- **Shape:** rails + nodes pattern forms internally (aligned geometry)
- **Material:** brushed metal exterior; energy underlayer
- **Animation:** rails align sequentially into a locked grid
- **Lighting:** violet/electric-blue protocol beams highlight edges
- **Scale:** stable and heavy; confidence tone
- **Meaning:** constraints become orchestration
- **Transition interaction:** compress streams into SOC-4, then release into fog boundary for BenefitBridge

### SOC-5 — ELIGIBILITY WEB HEART (BenefitBridge)
- **Shape:** branching connectivity lattice inside
- **Material:** stone/paper matte outer feel; warm emission inner paths
- **Animation:** paths ignite progressively from isolated points
- **Lighting:** civic warm-green/amber glow; calm and generous
- **Scale:** grows softly as connectivity increases
- **Meaning:** accessibility achieved by matching
- **Transition interaction:** lattice collapses into a compact glowing heart that seeds Mavira OS instability

### SOC-6 — HARDENED KERNEL MONOLITH (Mavira OS)
- **Shape:** monolithic and strict; seams become security barrier lines
- **Material:** steel/stone hardened exterior
- **Animation:** stability lock (motion nearly stops after assembly)
- **Lighting:** cool steel key light; dim controlled emission at seams
- **Scale:** largest mass so far; reliability presence
- **Meaning:** reliability under pressure
- **Transition interaction:** absorbs glitches, quiets them, then dissolves into calm-warm space for Health Coach

### SOC-7 — MEMORY COMPRESSION RIBBON (Personal Health Coach)
- **Shape:** core + curved folding geometry; ribbon channel wraps around it
- **Material:** soft energy-liquid blend with matte boundaries
- **Animation:** continuous ribbon flow (smooth, unbroken)
- **Lighting:** warm rose diffusion + deep cyan accent; calm glow
- **Scale:** medium; focus remains on ribbon stream
- **Meaning:** guidance formed from compressed memory
- **Transition interaction:** ribbon steadies, signature completes next state and leads into ending orbit

### SOC-8 — COMPLETED IDENTITY SCULPTURE (Ending)
- **Shape:** final coherent sculpture combining monolith stability + internal channel elegance
- **Material:** final balanced mixture: hardened outer + controlled inner energy
- **Animation:** near-static; micro breathing only
- **Lighting:** stable neutral-cool key and soft rim
- **Scale:** hero center; silhouette unmistakable
- **Meaning:** evolution completed; next chapter waits
- **Transition interaction:** none after completion (silence exhale)

---

## 3. Signature Object Relationship to Camera
- Camera must treat it as the “center of gravity.”
- During transitions, camera passes *into* or *around* signature to imply absorption.
- Typography and portals must align with signature’s optical axis.

---

## 4. Signature Object Relationship to Story
Rule:
- SOC state changes must map to the emotional arc of the current project.

Mapping:
- SOC-2: reading contracts emotionally
- SOC-3: triage thresholds become stable
- SOC-4: chaos becomes deterministic rails
- SOC-5: isolation becomes connected accessibility
- SOC-6: system stability earned
- SOC-7: calm guidance formed
- SOC-8: completed journey identity
