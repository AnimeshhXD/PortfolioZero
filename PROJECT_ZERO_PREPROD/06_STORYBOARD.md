## 0. Document Intent
This is the movie storyboard. It defines for **each scene**:
- scene number & name
- purpose + emotion
- environment + lighting + composition
- camera position & camera path (checkpoint description)
- typography and motion
- animation timeline (beat list)
- scroll timeline (percentage mapping)
- transition (exit + entry)
- duration and optional audio suggestion
- signature object state
- expected emotional impact

Because implementation is forbidden, the “camera path” is described as **cinematic checkpoints**.

---

## 1. Global Signature Object State Model
Use this model for all scenes:
- **State S0:** dormant / latent core
- **State S1:** activated seed (initial glow)
- **State S2:** multi-channel growth (agents/systems)
- **State S3:** project-specific resonance (world-specific evolution)
- **State S4:** final completion (ending)

Exact geometry chosen later; this doc only defines state.

## 2. Scene 0 — Boot Sequence

### Scene Number
0

### Scene Name
Boot Sequence / Single Decision

### Purpose
Set tone. Establish that the experience is authored, contemplative, and confident.

### Emotion
Silence → contemplation → quiet resolve.

### Environment
Black void. Tiny ambient particles. A faint blue/controlled glow. No terminal UI.

### Lighting
- Minimal ambient key (blue-violet)
- Fog nearly absent; fog appears only as a boundary for text emergence.

### Composition
Center text in hero zone.
Whitespace dominates.

### Camera Position (checkpoint)
- Start: static, camera facing forward into void.
- Micro drift: negligible vertical drift.

### Camera Path
- Hold (0–20% of scene time)
- Slight push-in during sentence 2
- Settle back into hold.

### Typography
Two-sentence narrative, emerging from fog/light resolve:
1) “Every system begins with a single decision.”
2) “Mine was to build.”

### Animation Timeline (beat list)
- Beat 1 (0–2s): silence. particles drift.
- Beat 2 (2–5s): sentence 1 emerges (fog-to-ink).
- Beat 3 (5–7s): sentence 1 holds, then dissolves.
- Beat 4 (7–10s): sentence 2 emerges with slightly warmer key light.
- Beat 5 (10–14s): sentence 2 dissolves into particles.
- Beat 6 (14–20s): particles organize into a subtle “signature seed” silhouette (S1).

### Scroll Timeline
Because this is Scene 0 only, scroll controls subtle intensity:
- 0–20% scroll: keep black void + sentence 1
- 20–55% scroll: sentence 2 emergence
- 55–100% scroll: environment materializes and holds for transition readiness

### Transition
No next scene yet in this current implementation-only phase.
The exit is readiness-only: signature seed stabilizes.

### Duration
~20s emotional duration for first load (or scroll-completed equivalent).

### Audio Suggestion (optional)
- Deep sub drone at low volume.
- Soft impacts only on sentence emergence (very restrained).

### Signature Object State
S1 (activated seed). Evolves from word fragments.

### Expected Emotional Impact
The visitor feels: “This is not a website. This is a film I can inhabit.”
